# among-us-mod
this is going to be updated regularly and because its my first time using git hub expect bugs and glitches im also a solo creator so pushing
out updates will be hard to balance with school
 Adds two roles and a host-only lobby panel.

- **Sheriff** (Crewmate): Shoot an Impostor to kill them; a misfire kills the Sheriff.
- **The Chosen One** (Impostor): Judgment kills any player, including other Impostors and the Sheriff. Keeps normal kill/vent/sabotage.

**Install:** extract the zip into your Among Us folder (BepInEx 6 IL2CPP x86 required). Full instructions are in README.md inside the zip.

Bundled: MiraAPI 0.6.0 and Reactor 2.5.0-ci.371 (patched for the SteamGG/itch 2026.9.29 build; use `extras/Reactor.dll.original` on Steam).
