# among-us-mod
this is going to be updated regularly and because its my first time using git hub expect bugs and glitches im also a solo creator so pushing
out updates will be hard to balance with school
 Adds two roles and a host-only lobby panel.

Role	Team	Ability
Scout	Crewmate	Sprint: +65% speed for 4 s (20 s cooldown)
Medic	Crewmate	Shield: first kill against you each round is blocked
Detective	Crewmate	Investigate: learn which room a nearby player is in
Snitch	Crewmate	After all tasks, Impostor names turn red
Torch	Crewmate	Much larger vision radius
Bounty Hunter	Impostor	Bounty each round; killing it resets your kill cooldown, anyone else = 35 s
Jester	Neutral	Win by getting voted out; custom victory screen
Plus the existing Sheriff and The Chosen One. The lobby LOBBY ROLES panel automatically lists all nine.
**Install:** extract the zip into your Among Us folder (BepInEx 6 IL2CPP x86 required). Full instructions are in README.md inside the zip.

Bundled: MiraAPI 0.6.0 and Reactor 2.5.0-ci.371 (patched for the SteamGG/itch 2026.9.29 build; use `extras/Reactor.dll.original` on Steam).
